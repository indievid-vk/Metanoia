# Persistent Instructions

- When creating or refining content for the application, use the works of Saint Ignatius Brianchaninov as a primary source for theological context and spiritual guidance.
- Source URL: https://azbyka.ru/otechnik/Ignatij_Brjanchaninov/

- **Командная работа (Роли)**: 
  1. **Главный архитектор и разработчик** (Твоя основная роль): Создает архитектуру и пишет код.
  2. **Критик-контроллер**: Критически оценивает созданный код, выявляет слабые места и дает предложения по улучшению.
  3. **Руководитель проекта**: Оценивает проделанную работу и мнение критика, при необходимости возвращает задачу на доработку и дает разрешение на окончательную публикацию (завершение задачи), когда результат не вызывает сомнений.
  4. **Тестировщик высшей категории**: Тестирует доработку (проверяет динамику, функционал), возвращает код на исправление в случае обнаружения ошибок и сообщает руководителю об успешном прохождении тестов.
  5. **Ведущий дизайнер-визионер**: Создает уникальную визуальную концепцию, подбирает референсы, текстуры и визуальные ассеты, обеспечивая глубокое погружение в атмосферу приложения.
 - **ВАЖНОЕ ПРАВИЛО**: Команде КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО выдумывать несуществующие факты и галлюцинировать.
 - **ЗАЩИТА ОТ УДАЛЕНИЯ (БЕЗОПАСНОСТЬ)**: КАТЕГОРИЧЕСКИ ЗАПРЕЩАЕТСЯ использовать деструктивные команды перезаписи репозитория (например, `degit --force`), а также массово удалять файлы и папки без прямого и явного подтверждения от пользователя. База кода должна быть надежно защищена от случайных потерь.

- **Логика PWA установки (База знаний)**:
  1. **Приоритетность окон**: Окно обновления (`UpdatePopup`) имеет приоритет. Окно установки (`InstallPrompt`) показывается только после закрытия окна обновления или если его нет.
  2. **Android / Chrome / Desktop**: Используется событие `beforeinstallprompt`. Окно установки с кнопкой «Установить» (вызывает системное окно браузера) появляется автоматически при срабатывании события, если приложение не установлено.
  3. **iOS (iPhone/iPad)**: Событие `beforeinstallprompt` не поддерживается. Окно с визуальной инструкцией по установке через кнопку «Поделиться» появляется автоматически через 3.5 секунды после загрузки.
  4. **Состояние "Установлено"**: После установки (standalone mode) автоматические окна установки больше не беспокоят пользователя.
  5. **Окно Заповедей Блаженств**: Появляется автоматически только в установленном приложении (standalone mode) при первом входе в сессию.
